01 / Problem

Make long URLs
easier to share.

The project explores the core mechanics of a URL shortening service: accepting a long URL, generating a compact identifier, storing the mapping, and resolving that identifier later.

01

Input

A user provides the original destination URL through the application.

02

Identifier

A short ID is generated so the original address can be referenced compactly.

03

Persistence

The mapping is stored in MongoDB so the short URL can be resolved later.

What the project
